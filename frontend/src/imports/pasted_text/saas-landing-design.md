Design a premium dark-mode SaaS landing page with a cinematic parallax scrolling experience.

The page should feel modern, polished, premium, and production-ready — inspired by high-end SaaS and developer products, but without looking overly futuristic, neon, cyberpunk, or “vibe coded.”

PRIMARY GOAL:
Create a landing page that uses layered scrolling depth and sticky product storytelling so that as the user scrolls, different visual layers appear to move at different speeds.

VISUAL DIRECTION:

- dark neutral background, not pure black
- restrained accent color
- premium typography
- subtle borders
- minimal gradients
- no excessive glow
- no glassmorphism overload
- no giant rounded cards everywhere
- no random floating shapes
- no gaming or crypto visual language

PARALLAX STRUCTURE:

1. HERO SECTION
   Create a full-screen hero with:

- strong headline
- concise subheading
- primary CTA
- secondary CTA
- large product/dashboard mockup
- subtle background grid or ambient gradient layer

Parallax intention:

- background layer moves slowest
- product mockup moves at medium speed
- foreground text moves slightly faster
- create strong sense of depth

Do not make the hero feel busy.

2. HERO-TO-PRODUCT TRANSITION
   As the user scrolls:

- hero text gradually moves upward
- dashboard mockup becomes more dominant
- background remains slow
- product mockup appears to move closer toward the center of the viewport

Design this transition so it can later be reproduced using scroll animation.

3. STICKY PRODUCT SHOWCASE
   Create a premium sticky product showcase section.

Place a large browser/device/product mockup in the center.

The mockup should visually remain anchored while feature content changes around it.

Structure:

Left side:
feature title + short explanation

Center:
large product UI mockup

Right side:
small feature callout card or metric

As scrolling progresses, show 3–4 different product features.

Example sequence:
Feature 1 → AI dashboard
Feature 2 → analytics
Feature 3 → automation
Feature 4 → insights

Each feature should feel like a new “chapter” of the scroll experience.

4. DEPTH LAYERS
   Build each major section using three visual depth layers:

BACKGROUND LAYER

- subtle grid
- ambient gradient
- faint large shapes
- very low contrast

MIDGROUND LAYER

- product screenshots
- dashboard frames
- illustrations

FOREGROUND LAYER

- text
- CTA
- feature callout cards

Design them so different layers can move independently during scroll.

5. FEATURE REVEAL SECTION
   Create a section where feature cards appear from different depths.

Use:

- slight vertical offset
- slight scale difference
- staggered positioning

Do NOT:

- rotate cards randomly
- use 3D tilt
- use extreme perspective
- use giant floating blobs

6. METRICS SECTION
   Create a clean metrics/proof section.

Use:

- 3–4 KPI cards
- large numbers
- short labels
- subtle motion-ready layout

The background should remain visually quiet while KPI cards feel like they rise slightly into the foreground.

7. TESTIMONIAL / TRUST SECTION
   Use:

- premium testimonial card
- company/user logos
- simple neutral layout

Avoid carousel-heavy design unless necessary.

8. FINAL CTA
   Create a strong final CTA section that feels like the foreground layer of the entire page.

Use:

- centered CTA card
- large headline
- primary button
- soft elevated surface
- subtle background depth effect

The CTA should feel like it is visually rising above the page.

PROTOTYPE / SCROLL BEHAVIOR TO PREPARE FOR:

Design the page so it can support:

- sticky product mockups
- scroll-linked transitions
- layered parallax movement
- fade + translate reveals
- section-by-section storytelling
- subtle scale changes
- background moving slower than content
- foreground moving slightly faster than background

Suggested depth behavior:

Background:
20–30% scroll speed

Midground:
50–70% scroll speed

Foreground:
90–100% scroll speed

Do not visually overdo the difference.

MOTION STYLE:

- subtle
- smooth
- restrained
- cinematic
- premium
- no bouncing
- no neon glow animation
- no exaggerated scale
- no constant floating movement

UI QUALITY:
The final page should look like:
“a premium SaaS startup landing page designed by an experienced product designer.”

Not:
“an AI-generated landing page with random scroll effects.”

FIGMA ORGANIZATION:
Use clearly named layers and groups:

/Background
/Midground
/Foreground
/Hero
/Product Showcase
/Feature 01
/Feature 02
/Feature 03
/Metrics
/Testimonials
/CTA

Use Auto Layout wherever possible.

Keep each parallax layer separate so it can later be animated independently.

Also create or prepare multiple prototype states for:

- hero
- transition
- feature 1
- feature 2
- feature 3
- metrics
- CTA

The final result should be visually ready for Smart Animate prototyping and easy developer handoff for real parallax implementation using GSAP ScrollTrigger, Motion/Framer Motion, or CSS scroll-driven animations.
